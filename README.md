# Outpost Omega (Unity)

The 3D version of Outpost Omega's Command mode, being ported from the Python game in
`D:\Personal Projects\Outpost-Omega-Updated`. The Python game stays the reference while this catches up.

## Status: phase 1 (look test)
Open the project, open `Assets/Outpost/Scenes/Sandbox.unity` (menu **Outpost > Open Sandbox Scene**)
and press Play. It loads an exported battlefield, builds both bases as connected complexes and lines up
both armies so you can fly around. No gameplay yet.

Controls: WASD / arrow keys / screen edges pan, mouse wheel zooms, Q / E or middle-mouse drag rotate,
Backspace resets the rotation. The panel in the top left switches maps.

## Where content comes from
Everything under `Assets/StreamingAssets/Outpost/` is generated by the Python project:

    python tools/export_unity.py "<this project>/Assets/StreamingAssets/Outpost" all

- `models.pak.json` / `models.pak.bin`  every unit, building and turret as a mesh (from the same sculpts as the 2D sprites)
- `maps/`    battlefields: tiles, sites, relays, crates, painted ground albedo and height field
- `data/`    the game's JSON data (units, buildings, tech, campaign, Siege Run...)

Scale: 1 Unity unit = 10 game pixels. Game map (x, y-down) maps to Unity (x, -z).

## Code layout
- `Assets/Outpost/Scripts/Content`  loading exported models and maps
- `Assets/Outpost/Scripts/View`     camera and presentation
- `Assets/Outpost/Scripts/Sandbox`  the phase-1 look test
- `Assets/Outpost/Editor`           the Outpost menu
